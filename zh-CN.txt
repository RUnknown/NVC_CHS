If you want to send audio over HDMI or DisplayPort, for example to a connected TV, then this component is required.\n\nIt is not required to have in-game audio through a sound card or your motherboard's audio outputs.=如果想通过 HDMI 或 DisplayPort 输出音频（例如连接电视），则需要此组件。\n\n通过声卡或主板音频输出获得游戏内声音，并不需要此组件。
ShadowPlay lets you record, share and stream gameplay. It also has an instant replay feature.\n\nHardware requirements are lower than other technologies because it uses an optimized capture and encoding path with hardware-acceleration.=ShadowPlay 可让你录制、分享并直播游戏画面，还带即时回放功能。\n\n由于采用硬件加速的优化采集与编码路径，它对硬件的要求低于其他技术方案。
This component enhances the Windows built-in multi-monitor support by adding multiple virtual desktops, to which you can assign applications, and quickly switch between desktops.\n\nNVIDIA Quadro View can only be installed on professional cards like Quadro or NVS.=此组件通过增加多个虚拟桌面来增强 Windows 自带的多显示器支持，你可以为虚拟桌面分配应用并在它们之间快速切换。\n\nNVIDIA Quadro View 只能安装在 Quadro 或 NVS 等专业显卡上。
This component is required for the graphics card to function.\n\nIt provides the low-level capability needed by Windows to recognize the card and display output on it.=此组件是显卡正常工作所必需的。\n\n它提供 Windows 识别显卡并在其上输出画面所需的底层能力。
This component provides services for other (non-essential) components to use.\nFor example crash reporting and telemetry uses the networking capabilities provided by NV Container.\n\nUnless you plan on installing NvApp, GeForce Experience or Telemetry, this is not needed.=此组件为其他非必要组件提供服务。\n例如，崩溃报告与遥测功能会使用 NV Container 提供的网络能力。\n\n除非你打算安装 NvApp、GeForce Experience 或遥测组件，否则不需要此项。
This is the older NVIDIA control panel, that's accessible via right-click on your desktop. It works standalone, without any other components.\n\nWhen you install the NVIDIA App, this component is required to provide game profile support, otherwise you will see an 'unable to retrieve settings' error.=这是旧版 NVIDIA 控制面板，可通过桌面右键访问。它独立运行，不依赖其他组件。\n\n安装 NVIDIA App 时需要此组件来提供游戏配置文件支持，否则会出现“无法检索设置”错误。
NVIDIA FrameView is an application for measuring framerates, frame times, power, and performance-per-watt on a wide range of graphics cards.\n\nThe NVIDIA App uses FrameView to get the sensor data for display in the in-game overlay. Without this component, the overlay will not show any data. MSI Afterburner overlay is a good alternative.=NVIDIA FrameView 是一款用于测量多种显卡的帧率、帧时间、功耗与每瓦性能的工具。\n\nNVIDIA App 使用 FrameView 获取传感器数据以显示在游戏内叠加层。没有此组件，叠加层将不显示任何数据。MSI Afterburner 的叠加层是个不错的替代方案。
Telemetry sends collected data from your system to NVIDIA, so they can improve their products and services.\n\nAccording to NVIDIA, the data contains hardware and software configuration, games (including settings, usage, and how well they run), feature usage, and your geographical region.=遥测功能会把从你的系统收集的数据发送给 NVIDIA，以便他们改进产品与服务。\n\n据 NVIDIA 说明，这些数据包含软硬件配置、游戏（含设置、使用情况与运行表现）、功能使用情况以及你所在的地理区域。
This component adds GPU power management support for notebooks. It enables dynamic boost and configurable TDP, and is required for proper operation of all GeForce RTX 30 laptop GPUs and newer.\n\nIf you don't install it, the NVIDIA GPU will fallback to a low-power mode.=此组件为笔记本增加 GPU 电源管理支持。它启用 Dynamic Boost 与可配置 TDP，是 GeForce RTX 30 及更新笔记本 GPU 正常工作所必需的。\n\n如果不安装，NVIDIA GPU 将回退到低功耗模式。
This components adds support for the on-board USB-C output of some GeForce 20 (Turing) graphics cards.\n\nIf you don't have a Turing graphics card, or don't plan to use the USB-C port, then this isn't needed.=此组件增加对部分 GeForce 20（Turing）显卡板载 USB-C 输出的支持。\n\n如果你没有 Turing 架构显卡，也不打算使用 USB-C 接口，则不需要此组件。
This package provides audio recording capability for ShadowPlay\n\nOnly install this if you want to record gameplay using ShadowPlay.=此包为 ShadowPlay 提供音频录制能力。\n\n只有想用 ShadowPlay 录制游戏画面时才需要安装。
NVIDIA PhysX is a software library for games to simulate physical interaction between objects.\n\nOnly few games support this technology nowadays, most games come with their own implementation of physics simulation.=NVIDIA PhysX 是供游戏模拟物体间物理交互的软件库。\n\n如今支持这项技术的游戏已不多，多数游戏自带物理模拟实现。
